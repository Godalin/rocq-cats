# Limit and colimit models in sets

# 集合中的极限与余极限模型

Sets are the library's setoids, and their specified equality is strict equality.
The models below retain Type-valued witnesses and transparent mediators.
They introduce no quotient axiom, choice, function extensionality, UIP,
proof irrelevance or universe resizing.

集合就是本库的广集，其指定相等就是严格相等。下面的模型保留 Type 值见证及
透明中介，不引入商公理、选择、函数外延性、UIP、证明无关性或宇宙大小重设。

## Primitive models and shared constructors

## 原始模型与共用构造

| Model / 模型 | Implementation / 实现 |
| --- | --- |
| Terminal / 终对象 | [Terminal](../theories/Instance/Set/Terminal.v): singleton / 单点集 |
| Initial / 始对象 | [Initial](../theories/Instance/Set/Initial.v): empty set / 空集 |
| Binary product / 二元积 | [Product](../theories/Instance/Set/Product.v): coordinatewise equality / 逐坐标相等 |
| Pullback / 拉回 | [Pullback](../theories/Instance/Set/Pullback.v): pairs with an image-equality witness / 携带像相等见证的坐标对 |
| Equalizer / 等化子 | [Equalizer](../theories/Instance/Set/Equalizer.v): existing diagonal-pullback theorem / 已有对角拉回定理 |
| Binary coproduct / 二元余积 | [Coproduct](../theories/Instance/Set/Coproduct.v): foundational disjoint sum / 基础不交和 |
| Coequalizer / 余等化子 | [Coequalizer](../theories/Instance/Set/Coequalizer.v): generated specified equality / 生成指定相等 |
| Pushout / 推出 | [Pushout](../theories/Instance/Set/Pushout.v): existing coproduct/coequalizer theorem / 已有余积及余等化子定理 |

[Sum](../theories/Set/Sum.v) compares elements within their summand and makes
different summands disjoint. [Generated](../theories/Set/Generated.v) constructs
the equivalence closure of a Type-valued relation and proves its leastness:
a map preserving the generators preserves their entire closure.
Its derivations retain intermediate elements and witnesses as data.

[Sum](../theories/Set/Sum.v) 在每个加数内比较元素，区分不同加数。
[Generated](../theories/Set/Generated.v) 构造 Type 值关系的等价闭包并证明其最小性：
保持生成元的映射保持整个闭包。推导将中间元素及见证保留为数据。

For parallel maps `f,g : X →r Y`, `CoeqS f g` keeps the carrier of `Y`.
Its equality is generated by the original equality of `Y` and the pairs
`f x ≈ g x`. The projection is identity on representatives; a coequalizing
map descends with the same underlying function. Uniqueness compares values.
The chosen structure supplies the original opposite equalizer fields.

对于平行映射 `f,g : X →r Y`，`CoeqS f g` 保留 `Y` 的载体，由 `Y` 原有相等及
`f x ≈ g x` 生成其相等。投影在代表上为恒等，余等化映射以同一个底层函数下降；
唯一性比较值。选定结构直接提供原反等化子字段。

## Indexed and diagram models

## 指标及图式模型

[Pi](../theories/Set/Pi.v) supplies raw dependent functions with pointwise
equality, `∏S[D]`. This construction was extracted from
[Fam.Core](../theories/Instance/Set/Fam/Core.v); its index can now be any
type, and it has no category dependency. These raw functions do not impose
coherent-section laws. [IndexedSum](../theories/Set/IndexedSum.v) supplies
`∐S[D]`, using a dependent-sum carrier and equality generated within each fiber.
No equality of transport or derivation witnesses is required.

[Pi](../theories/Set/Pi.v) 提供带逐点相等的原始依赖函数 `∏S[D]`。
该构造从 [Fam.Core](../theories/Instance/Set/Fam/Core.v) 提取出来，索引现在可以为
任意类型，且不依赖范畴；这些原始函数不要求相干截面定律。
[IndexedSum](../theories/Set/IndexedSum.v) 提供 `∐S[D]`，载体为依赖和，相等由
每个纤维内的相等生成，不要求运输或推导见证相等。

[Limit](../theories/Instance/Set/Limit.v) and
[Colimit](../theories/Instance/Set/Colimit.v) provide explicit choices for:

[Limit](../theories/Instance/Set/Limit.v) 与
[Colimit](../theories/Instance/Set/Colimit.v) 显式提供以下选择：

- Indexed products and coproducts, including finite and dependent-sum indices.
- General diagrams, using the two object/arrow-indexed products or coproducts.
- Free graph shapes, using vertices and generators rather than all paths.
- Finite hom covers and finitely generated shapes, including cyclic graphs.

- 指标积及余积，包括有限索引及依赖和索引。
- 一般图式，使用对象及箭头索引的两个积或余积。
- 自由图形状，只使用顶点及生成元，不按全部路径索引。
- 有限 Hom 覆盖及有限生成形状，包括含环图。

Only the indexed setoid models need new universal-property proofs here.
The diagram, finite, graph and pushout models instantiate the existing general
theory. Colimit models supply its original opposite-limit data; no second
colimit theory is maintained. Finite products/coproducts use the binary models
and terminal/initial objects, preserving their weaker size requirements.

这里只有指标广集模型需要新的泛性质证明；图式、有限、图及推出模型都实例化
已有通用理论。余极限模型提供原反极限数据，不维护第二套余极限理论。
有限积／余积使用二元模型及终／始对象，从而保留较弱的大小要求。

Imports do not globally activate any chosen model structure. Pass a named
choice explicitly, or enable the relevant `SetCat_Has*` definition locally.
The base [SetCat](../theories/Instance/Set/Core.v) module still depends only
on the category core; extensions are imported individually.

导入不会全局启用任何选定模型结构。应显式传入具名选择，或局部启用所需的
`SetCat_Has*` 定义。基础 [SetCat](../theories/Instance/Set/Core.v) 模块仍只依赖
范畴核心，各扩展分别导入。

## Universe boundaries of these models

## 这些模型的宇宙边界

Write `u` for the carrier level, `p` for its equality-witness level, and `i`
for an indexing carrier level. Auxiliary law universes remain inferred.
The following restrictions describe these implementations, not a limitation
on the abstract categorical interfaces or a nonexistence theorem.

用 `u` 表示载体层级，`p` 表示相等见证层级，`i` 表示索引载体层级；辅助定律宇宙
仍由系统推断。以下限制描述当前实现，不是抽象范畴接口的限制或不存在性定理。

| Model / 模型 | Bounds / 大小界 |
| --- | --- |
| Binary/finite products and coproducts / 二元及有限积、余积 | No ordering of `u,p` / 不比较 `u,p` |
| Raw indexed products / 原始指标积 | `i ≤ u`, `i ≤ p` |
| Generated indexed coproducts / 生成指标余积 | `i ≤ u ≤ p` |
| Pullbacks, equalizers / 拉回、等化子 | `p ≤ u` |
| Coequalizers, pushouts / 余等化子、推出 | `u ≤ p` |
| General diagram/free-graph limits / 一般图式、自由图极限 | Index carriers `i ≤ p ≤ u` / 索引载体 `i ≤ p ≤ u` |
| General diagram/free-graph colimits / 一般图式、自由图余极限 | Index carriers `i ≤ u ≤ p` / 索引载体 `i ≤ u ≤ p` |
| Finite/finitely generated limits / 有限及有限生成极限 | `p ≤ u`; no raw shape-carrier bound / 不约束原始形状载体 |
| Finite/finitely generated colimits / 有限及有限生成余极限 | `u ≤ p`; no raw shape-carrier bound / 不约束原始形状载体 |

Pullback carriers contain equality witnesses, explaining `p ≤ u`.
Generated equality derivations store intermediate carrier elements, explaining
`u ≤ p`. At `u = p`, both constructions can be used together. Shape equality
witnesses may be larger than both target levels: only object/arrow or
vertex/generator carriers enter the indexing bounds.

拉回载体包含相等见证，因此需要 `p ≤ u`；生成相等推导保留中间载体元素，因此
需要 `u ≤ p`。在 `u = p` 时可以同时使用两类构造。形状的相等见证可以大于
两个目标层级，只有对象／箭头或顶点／生成元载体进入索引大小界。

## Validation

## 验证

With Rocq 9.0.1, OCaml 5.3.0 and Nix Dune 3.23.1, the full build, test and
install targets pass. Permanent [universe checks](../tests/Universes.v) cover
both admissible level orderings, the two model-specific boundaries, larger
shape witnesses and finite/generated shapes with larger raw carriers.
[Interface checks](../tests/Interfaces.v) guard explicit activation.

在 Rocq 9.0.1、OCaml 5.3.0 与 Nix Dune 3.23.1 下，完整构建、测试及安装目标通过。
永久[宇宙检查](../tests/Universes.v) 覆盖可接受的两种层级排列、两项模型边界、
更大的形状见证及原始载体更大的有限／有限生成形状；
[接口检查](../tests/Interfaces.v) 保证显式启用结构。

Fifty temporary assumption checks report no additional assumptions. Fifteen
temporary computation checks include coequalizers identifying distinct native
representatives, the action on equality derivations, binary and indexed
mediators, general-diagram mediators and a finite graph with a loop changing
representatives. These fixtures remain outside the theory library. Eleven
coqdoc pages were generated and parsed successfully. These are local checks.

50 项临时公理检查均无额外假设。15 项临时计算检查包括识别原生不同代表的
余等化子、相等推导上的作用、二元及指标中介、一般图式中介，以及环会改变代表
的有限图。相关实例保留于理论库之外；11 个 coqdoc 页面生成并解析通过。
这些结果属于本地验证。
